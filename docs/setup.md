## 1. Таблиця з книгами

1. Каталог має бути **Google Таблицею**. Якщо це файл `.xlsx`, відкрийте його й виберіть
   **Файл → Зберегти як Google Таблиці** — Apps Script не читає xlsx.
2. Перший рядок — заголовки: `№`, `Автор`, `Назва`, `Рік`, `Сторінки`, `Ціна`, `К-сть`
   (решту колонок додасть крок 3; що в яку писати — у [catalog.md](catalog.md)).
3. Скопіюйте **ID таблиці** — частину посилання між `/d/` і `/edit`.

Якщо книги не на першому аркуші, запам'ятайте назву аркуша — знадобиться в кроці 3.

## 2. Папка з фото (необов'язково)

1. Створіть на Google Диску папку, напр. «Обкладинки».
2. **Поділитися → Загальний доступ → Усі, хто має посилання → Читач.**
3. Скопіюйте **ID папки** — частину посилання після `/folders/`.

Як називати фото — у [catalog.md](catalog.md#фото).

## 3. Таблиця замовлень і скрипт

1. Створіть нову Google Таблицю, напр. «Замовлення книг». Сюди падатимуть замовлення.
2. У ній: **Розширення → Apps Script**. Замініть вміст редактора на `apps-script/Code.gs` з репозиторію.
3. Угорі файлу заповніть:
   - `CATALOG_ID` — ID таблиці з книгами (крок 1);
   - `CATALOG_SHEET` — назва аркуша з книгами, якщо він не перший; інакше лишіть `''`;
   - `PHOTOS_FOLDER` — ID папки з фото (крок 2), якщо є.
4. Збережіть (значок дискети).
5. Угорі редактора виберіть функцію **`setupCatalog`** → **Виконати** → дозвольте доступ
   (Google попередить, що застосунок не перевірений, — це ваш власний скрипт: натисніть **Додатково**
   і перейдіть до проєкту).
   Функція створить у таблиці з книгами аркуш «Категорії» і додасть колонки `Категорія`, `Стан`, `Обкладинка`,
   `Мова`, `Видавництво`, `Акційна ціна`, `ISBN` з випадними списками. Повторний запуск нічого не зламає.
6. Якщо вказали `PHOTOS_FOLDER`: виберіть функцію **`doGet`** → **Виконати**, щоб дозволити скрипту читати Диск.
7. **Розгорнути → Нове розгортання** → значок шестерні → **Веб-застосунок**:
   - Виконувати як: **Я**;
   - Хто має доступ: **Усі**.
8. **Розгорнути**, скопіюйте **URL веб-застосунку** (`https://script.google.com/macros/s/…/exec`).
   Відкрийте його в браузері — має показатися текст, що починається з `{"ok":true,"books":[`.

Аркуші «Замовлення» і «Позиції» в таблиці замовлень створяться самі з першим замовленням.

**Помилка при запуску?** Найчастіше скрипт не знайшов аркуш з книгами — текст помилки підкаже,
які аркуші є в таблиці; виправте `CATALOG_SHEET`.

## 4. Сповіщення в Telegram (необов'язково)

Про кожне нове замовлення приходитиме повідомлення: контакти, доставка, оплата, книги й сума.

1. У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot`, скопіюйте **токен** бота.
2. Напишіть своєму боту будь-що — інакше він не зможе писати вам першим.
3. Відкрийте в браузері `https://api.telegram.org/bot<токен>/getUpdates` і знайдіть `"chat":{"id":…}` — це **chat_id**.
   Для групи: додайте бота в групу, напишіть там щось і візьміть `id` групи (він від'ємний).
4. В Apps Script: **Налаштування проєкту (шестерня) → Властивості скрипта → Додати**:
   `TELEGRAM_TOKEN` — токен, `TELEGRAM_CHAT_ID` — chat_id.
   **Не вписуйте їх у `Code.gs`** — репозиторій публічний.
5. Виберіть функцію **`testTelegram`** → **Виконати** → дозвольте доступ до зовнішніх сервісів.
   Має прийти тестове повідомлення.
6. Зробіть нову версію розгортання (див. рамку вгорі).

Якщо Telegram недоступний, замовлення все одно записується в таблицю.

## 5. Сайт на GitHub Pages

1. У `js/catalog.js` вставте URL веб-застосунку (крок 3) у `const API_URL = '…'`.
2. У файлі `CNAME` — ваш домен, лише домен: `shop.example.com`.
3. Запуште репозиторій на GitHub.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
5. Там же **Custom domain** — той самий домен, що в `CNAME` → **Save**. GitHub покаже, який DNS-запис додати
   в реєстратора домену (для піддомену — `CNAME` на `<логін>.github.io`). Коли перевірка пройде — **Enforce HTTPS**.
6. Вкладка **Actions** → «Сайт» має пройти зеленим (або **Run workflow**, щоб запустити вручну).

Далі сайт оновлюється сам: після кожного пушу в `main` і щогодини (сторінки книг встигають за таблицею).
Що означають попередження в Actions — у [catalog.md](catalog.md#попередження-при-збиранні).

### Перевірка
- [ ] Головна показує книги, пошук і фільтри працюють.
- [ ] Клік по книзі відкриває картку; `https://<домен>/book/<№>/` — окрема сторінка книги.
- [ ] Тестове замовлення з'явилося в аркуші «Замовлення» (і в Telegram, якщо налаштовано). Потім видаліть його.
- [ ] У підвалі відкриваються «Доставка й оплата», «Повернення», «Контакти» — і в них немає підсвічених
      незаповнених місць (див. [catalog.md](catalog.md#сторінки-для-покупців)).
- [ ] Посилання на сайт, надіслане собі в Telegram, показує прев'ю з картинкою
      (Telegram кешує прев'ю; оновити — бот [@WebpageBot](https://t.me/WebpageBot)).

### Змінити домен, назву, іконку
- **Домен:** файл `CNAME` і **Settings → Pages → Custom domain** (+ DNS-запис). Більше ніде домен не записаний.
- **Назва магазину:** в `index.html` — заголовок шапки (`<h1 class="brand">`) і `<title>`;
  опис для Google — `<meta name="description">`. Потім перемалюйте картинку прев'ю
  (Python і `pip install pillow`): `python scripts/og-image.py "Перший рядок" "Другий рядок"`.
- **Іконка:** `<link rel="icon">` в `index.html` (SVG прямо в рядку) і `apple-touch-icon.png` (180×180).

## 6. Google Пошук (Search Console)

Робіть на постійному домені: підтвердження прив'язане до адреси.

1. [Google Search Console](https://search.google.com/search-console) → **Додати ресурс** →
   **Префікс URL-адреси** → `https://<домен>/`.
2. Підтвердження: найпростіше **DNS** (запис TXT у реєстратора домену) або **HTML-тег** —
   рядок `<meta name="google-site-verification" …>` додайте в `<head>` `index.html` поруч з іншими `meta`,
   опублікуйте сайт і натисніть «Підтвердити». Тег не видаляйте.
3. **Файли Sitemap** → `sitemap.xml`.
4. **Перевірка URL-адреси** → адреса сайту → **Надіслати запит на індексування**.

## 7. Google Покупки (Merchant Center)

Безкоштовний показ книг у вкладці «Покупки», у Зображеннях і Google Lens.
Перед цим: постійний домен, заповнені сторінки «Контакти» й «Повернення» (Google їх перевіряє)
і фото книг — без фото товар не покажуть.

1. [merchants.google.com](https://merchants.google.com) → створіть акаунт, країна — Україна.
2. Підтвердіть і закріпіть сайт (так само, як у кроці 6).
3. Налаштуйте **доставку** (вартість і терміни) та **правила повернення** — як на сторінках сайту.
4. **Продукти → Джерела даних → Додати** → «Додати товари з файлу» → **за посиланням** →
   `https://<домен>/products.xml`, оновлення — щодня.

Що потрапляє у файл товарів — у [catalog.md](catalog.md#google-покупки).
